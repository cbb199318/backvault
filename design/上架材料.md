## 一、安装包

| 架构 | 文件 | 大小 | 说明 |
|---|---|---|---|
| x86_64 | `encbackup.fpk` | 42 MB | `platform=x86` |
| ARM64 | `encbackup-arm.fpk` | 38 MB | `platform=arm`，同一 appname、同一版本号 |

两个包内容一致，只是 `app/server/encbackup-server`、`app/server/engines/restic`、`app/server/engines/rclone` 换成了对应架构的二进制；前端静态资源是同一份。

重新打包：

```bash
# x86
./build.sh                     # 会重新构建前端 + 后端 + 拉 /tmp/encbin 里的引擎
# arm（后端交叉编译 + 引擎取自 /tmp/encbin-arm）
GOOS=linux GOARCH=arm64 CGO_ENABLED=0 go build -o /tmp/encbackup-server-arm64 ./backend
cp -R encbackup /tmp/fpk-arm/encbackup
cp /tmp/encbackup-server-arm64 /tmp/fpk-arm/encbackup/app/server/encbackup-server
cp /tmp/encbin-arm/{restic,rclone} /tmp/fpk-arm/encbackup/app/server/engines/
sed -i '' 's/platform=x86/platform=arm/' /tmp/fpk-arm/encbackup/manifest
cd /tmp/fpk-arm && /path/to/fnpack build --directory encbackup
```

引擎版本：restic 0.18.0、rclone v1.75.2，与运行时 `restic version` / `rclone version` 一致。

## 四、商店文案

**一句话简介**：基于 restic 的加密备份与快照还原，数据先加密再上传云盘。

**详细描述**（与 `manifest` 的 `desc` 一致）：

> 基于 restic 的加密备份与快照还原应用。向导式创建任务，定时把指定目录加密备份到天翼云盘 / 115 网盘 / 任意 WebDAV（OpenList 挂载）；支持浏览仓库快照、按目录或文件精确还原、查看备份与还原历史。数据在本机加密后再上传，云端只存密文；仓库密码与云盘凭据仅保存在本机 `/vol1/@appdata/encbackup`，仅管理员可读，界面与接口均做掩码处理。支持桌面与手机自适应界面。

**隐私说明**（审核会问，单独准备一份）：

- 备份内容：仅用户勾选的本地目录，写入用户配置的远端仓库（天翼 / 115 / WebDAV）。
- 仓库密码：每个任务随机生成，明文只存在 `/vol1/@appdata/encbackup/config.json`（权限 600，root 所有），接口返回时统一替换为 `******`。
- 云盘凭据：WebDAV 账号密码经 `rclone obscure` 处理后写入 rclone 配置，同样只在本机。
- 网络出向：仅访问用户自己配置的云盘地址；不向任何第三方上报数据，无遥测。
- 入向：应用只监听 `app.sock`（unix socket），通过飞牛网关 `/app/encbackup` 暴露，不额外开放 TCP 端口（`checkport=false`）。
