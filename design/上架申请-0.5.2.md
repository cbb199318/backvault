## 备注（整段复制）

```
量子密备 0.4.9 → 0.5.2 更新说明

一、安全：不再以 root 运行（本次最重要变更）
· 应用改为以专用用户 encbackup 运行（config/privilege: run-as=package），不再使用 root
· 备份源目录、还原目标目录需在 应用中心 → 量子密备 → 设置 → 授权目录 中授权后才能访问，未授权时界面会明确提示，不会越权读取
· 文件读写接口统一走路径校验：先解析软链接，再按分隔符边界比对授权目录，拒绝越界路径

二、多用户隔离
· 每位用户只能看到和操作自己创建的任务、云盘仓库、还原记录，管理员可见全部
· 普通用户只能使用自己添加的 WebDAV 云盘，不能使用管理员配置的天翼云盘 / 115 共享账号
· 导出恢复信息、配置备份、上传限速仅管理员可设置

三、问题修复
· 以应用用户运行时，还原到自定义目录的文件停留在临时目录、没有移动到目标位置（restic 还原出的目录权限为 000）

四、【审核测试指引】
1. 安装后请先在 应用中心 → 量子密备 → 设置 → 授权目录 勾选一个测试目录（如 /vol1/1000/test）
2. 打开应用 → 新建任务 → 备份源选该目录 → 目的地选「WebDAV」，填任意可写的 WebDAV 地址即可跑通完整流程（内置天翼云盘 / 115 需要管理员在 OpenList 中授权，测试环境可跳过）
3. 应用通过飞牛统一网关访问（app.sock，checkport=false），不监听任何公网端口

五、本次包内同时包含 0.4.5–0.4.9 的改动
· 界面改为 iOS 原生风格：系统色、大圆角分组列表，支持深色模式
· 新增「设置」页：云盘仓库集中管理（检测连接 / 查看加密密码）、一键导出恢复信息（NAS 损坏时凭它用 restic 取回数据）、配置备份与恢复、上传限速、外观切换
· 快照浏览改为逐层文件表格并支持全快照搜索；还原向导可回跳步骤；历史支持仅看失败与重新还原
· 应用内在线更新：GitHub 与国内镜像并行测速选源，更新包 ed25519 签名 + sha256 校验，新版本启动失败自动回滚
· 图标体系改为 Tabler 线性图标；云端仓库显示天翼云盘 / 115 / 百度网盘 / 阿里云盘官方标识
· 手机端（飞牛 App 内）修复标题上方空白、卡片紧凑化，电脑端窄窗口下表格逐级收起次要列

六、项目主页与用户交流

七、其他
```
