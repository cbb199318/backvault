三、关键判据：能不能跟随状态色

方案跟随状态色实现方式语义覆盖
A · Tabler 线性✅ 跟随currentColor 描边全覆盖
B · Phosphor Duotone✅ 跟随currentColor 填充 + 半透明层全覆盖
C · Phosphor Fill✅ 跟随currentColor 实心全覆盖
D · Solar Bold Duotone✅ 跟随currentColor 填充 + 淡色层全覆盖
E · Streamline Color❌ 固定 #4147d5硬编码 fill/stroke缺历史、还原
F · Soft 3D❌ 固定彩色渐变 + 光影全覆盖
G · Fluent Emoji❌ 固定彩色渐变缺历史、还原、设备

这是能不能用在列表行上的分水岭。A–D 用 currentColor， 状态一变图标跟着变；E–G 颜色写死在 SVG 里，成功/失败只能靠旁边的标签表达， 而彩色图标自带的颜色还可能误导（比如 Soft 3D 的时钟是红的，会被误读成出错）。

四、落地成本

方案改动范围工作量
B / D（单色或双色、跟随 currentColor） 只换 icons.js 里的路径表 + 删掉三处色块 CSS 约 1 小时，模板零改动
C（实心 + 实色底） 换路径表 + 改 .tt-ic / .hi-ic / .sn-ic / .rp-ic 四处底色规则 约 2 小时
E / F / G（彩色图标） 换路径表 + 移除所有 color 依赖 + 重新设计状态表达（色块不能再用） 半天以上，且要逐页核对语义

所有方案都不需要改组件结构：Icon.vue 用 v-html 注入路径， 只要把 icons.js 里的 stroke-width / 路径换成对应图标集即可。 彩色图标集要额外把 svg 的 fill="none" 去掉，否则部分填充图形会被裁掉。

五、我的建议：不用一套打到底，按位置分三档

位置用哪套理由
列表行（任务 / 仓库 / 历史）D · Solar Bold Duotone去掉彩色方块，图标直接着色。状态只在右侧标签说一次，最干净。
还原流程 / 目的地选择B · Phosphor Duotone双色调在大图标上比纯线性更有层次，20–24px 刚好。
空状态 / 首次引导F · Soft 3D一个页面只出现一次，立体感是加分项，不构成干扰。
导航 / 工具栏小图标A · Tabler（保留）16–17px 尺寸下双色会糊，线性反而最清楚。
